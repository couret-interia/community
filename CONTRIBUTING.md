# Contributing · InterIA Community

We welcome all forms of contribution — from typo fixes to discussions, from data scripts to proof reviews.

---

## 🧭 Quick Start / Démarrage rapide

1. **Fork** this repository → <http://github.com/couret-interia/community>
2. **Create a branch**:
   `git checkout -b feature/my-improvement`
3. **Commit your changes** with clear messages.
4. **Open a Pull Request** → describe the change and link related discussions.

## 🧪 FAIR⁺⁺ Principles

All contributions should follow FAIR⁺⁺ guidelines:

- **Findable** → clear filenames, metadata, keywords.
- **Accessible** → open licenses (MIT/CC-BY).
- **Interoperable** → structured data formats (CSV, JSON, Markdown).
- **Reusable** → documented, versioned, reproducible.
